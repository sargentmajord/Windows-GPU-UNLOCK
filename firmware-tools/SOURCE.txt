The installer (installer/Firmware.ps1) checks each script against these hashes before it runs it. Upstream's README says
Python 3.14 is needed; at this commit the scripts instead call the `zstd` command for the .zst package, so Python 3.12 and
zstd are enough (verified 2026-10-25 on Windows: all five generated files match internal-boot/unlock/assets.json).
